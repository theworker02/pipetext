# pipetext

Pipe identifiers and text tokens for idempotent workflows.

**Site:** https://theworker02.github.io/pipetext/

## Install / run

```bash
git clone https://github.com/theworker02/pipetext.git
cd pipetext
node src/cli.js
node --test
```
